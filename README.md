# Vortex — Static Website

Mobile-first, GitHub Pages-ready static site for the Vortex project.

## Files

- `index.html` — page structure and content
- `styles.css` — responsive liquid-glass neon UI
- `app.js` — mobile menu, reveal animations, article dialog
- `assets/` — image assets used by the site

## Run locally

Open `index.html` in a browser, or serve the folder with any simple static server.

## GitHub Pages

Upload the folder contents to a repository and enable GitHub Pages for the repository's branch/root. No build step is required.

## Download button

The Android download control is intentionally disabled and does not contain a URL. Replace it only when the final Vortex APK destination is known.

## Notes

The Roblox knowledge articles are original summaries with links to external references. Vortex is presented as a third-party project and not as an official Roblox service.
