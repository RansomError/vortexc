# Vortex Site

A mobile-first static site for Vortex. The project uses a black and neon-green liquid-glass visual system with lightweight motion and no framework dependency.

## GitHub Pages upload

Keep every file below in the repository root:

- `index.html`
- `styles.css`
- `app.js`
- `vortex-icon.webp`
- `roblox-community.webp`
- `roblox-history.webp`
- `roblox-experiences.webp`

Do not put these files inside another folder. `index.html` must be directly visible in the repository root.

In GitHub Pages, use **Settings → Pages → Deploy from a branch → main → / (root)**.

The Download button is intentionally disabled because no public APK destination has been supplied yet.

The site is a third-party project and is not affiliated with Roblox Corporation.
